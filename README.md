# Sinais Vitais — Monitor Multiparamétrico (Simulação)

Monitor de sinais vitais para simulação de Enfermagem, em um único `index.html`.

- **Parte 1:** PA 170/90 · FC 66 · SpO₂ 75% · FR 8–9
- **Parte 2:** PA 180/100 · FC 60 · SpO₂ 75% · FR 8–9
- Ondas de ECG, pletismografia e respiração
- Bipe do pulso (mais grave com SpO₂ baixa) e alarme de alta prioridade
- Botões para ligar/desligar o som, silenciar o alarme e trocar de parte

Abra o `index.html` no navegador (ou publique no GitHub Pages / Vercel).

> Simulação educacional — não é um equipamento médico.
